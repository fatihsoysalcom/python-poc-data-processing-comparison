# Python PoC Data Processing Comparison

This example demonstrates a Proof of Concept (PoC) by evaluating two different Python programming approaches for a common data processing task. It compares an imperative loop-based method with a functional list comprehension method, measuring their execution time and discussing factors like readability and resource usage. This mirrors how different technologies or architectural choices might be evaluated during a PoC phase to make informed decisions.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
